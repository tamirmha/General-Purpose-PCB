# How to integrate this into your project

1. Copy the `example_config.h` into your project's `Core/Inc/` folder.
2. Copy the entire `Examples` folder into your project's `Core/Src/` folder.
3. Open your project's `Core/Src/main.c` file.

Add this at the top of your `main.c` file:
/* USER CODE BEGIN Includes */
extern void Run_Example(void);
/* USER CODE END Includes */

Add this inside your `main()` function, right BEFORE the infinite while loop:
/* USER CODE BEGIN 2 */
Run_Example();
/* USER CODE END 2 */

THAT'S IT! 
Now, just open `example_config.h`, uncomment the feature you want to test, and click Build/Run. It will work flawlessly across STM32CubeIDE, VSCode, and CLion.
