# 8. CAN Bus

### 1) What to connect
* CAN High (CANH) and CAN Low (CANL) to the CAN terminal block.

### 2) Hardware Configuration: The 120R Jumper (J30)
* **Jumper ON**: Place the jumper cap on J30 if this board is the first or last node on your CAN bus.
* **Jumper OFF**: Remove the jumper cap if this board is wired into the middle of the bus.
